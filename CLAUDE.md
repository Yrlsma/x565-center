# Контекст проекта для Claude Code

Владелец проекта общается по-русски. Отвечай по-русски, интерфейс программы тоже на русском.

## Что это

X565 Center — настольная программа для Windows 11 на ноутбуке Maibenben X565
(платформа Tongfang/Uniwill, AMD Ryzen 5 6600H, встроенная Radeon 660M, дискретная GeForce RTX 3050 или 4050,
экран 1920×1080 144 Гц, Wi‑Fi MediaTek или Intel AX200). Программа работает рядом со штатным Control Center 5.52.49.5, не заменяя его.

Требования — в `docs/SPEC.md`. Оформление — в `docs/DESIGN.md`, исходники макетов — в `docs/mockups/`.
Код ещё не написан: начни с этапа 1 из `docs/SPEC.md`.

## Жёсткие ограничения

- Не писать в EC, ACPI и WMI-методы производителя. Никакого управления вентиляторами, лимитами мощности, подсветкой клавиатуры.
  Обороты вентиляторов — только чтение. Ошибка здесь может оставить ноутбук без охлаждения.
- Не декомпилировать и не копировать код штатного Control Center (Uniwill). Взаимодействие с ним — только запуск его ярлыка.
- Игровой режим не останавливает произвольные процессы и службы. Закрываются только программы из списка пользователя,
  приостанавливаются только службы из короткого списка в `docs/SPEC.md`, после игры всё возвращается.
- Изменение приоритета процесса игры отключается для каждой игры отдельно (античиты).
- Всё, что программа меняет в системе (схема питания, частота экрана, службы), должно возвращаться в прежнее состояние
  при выходе и после аварийного завершения (сохранять прежнее состояние на диск до изменения).

## Технологии

- Python 3.12+, PySide6.
- Датчики: `psutil`; видеокарта NVIDIA через `nvidia-smi` или NVML (`pynvml`);
  температура процессора и вентиляторы через LibreHardwareMonitorLib (нужны права администратора). Если датчик недоступен — плитка скрывается, программа не падает.
- Схемы питания: `powercfg`. Частота экрана: WinAPI `ChangeDisplaySettingsEx`.
- Настройки: JSON в `%APPDATA%\X565Center`. История графика — только в памяти.

## Как работать

- Программа запускается и проверяется на этом же ноутбуке: после каждого изменения запускай её и смотри на ошибки.
- Когда окно свёрнуто в трей, опрос датчиков раз в 3–5 секунд, график не рисуется.
- Целевой расход: до 150 МБ памяти, меньше 1% процессора в простое.
- Пиши по этапам из `docs/SPEC.md`, каждый этап — отдельная ветка и pull request.
