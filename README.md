# X565 Center

Своя панель управления для ноутбука Maibenben X565 (Ryzen 5 6600H, GeForce RTX 3050/4050, Windows 11).
Дополняет штатный Control Center: мониторинг, режимы питания, быстрые переключатели, трей и игровой режим.

Статус: описание и макеты готовы, код ещё не написан.

## Что будет в первой версии

1. Режимы «Тихий / Баланс / Турбо»: схема питания Windows + частота экрана (60/144 Гц).
2. Мониторинг: загрузка и температура процессора и видеокарты, память, обороты вентиляторов (только чтение, если ноутбук их отдаёт), батарея.
3. График температуры и загрузки за 10 минут.
4. Быстрые переключатели: частота экрана, Wi‑Fi, Bluetooth, яркость.
5. Окно из трея в теме основной панели.
6. Тёмная и светлая тема, переключатель в шапке раздела «Обзор».
7. Автозапуск с Windows и горячие клавиши смены режима.
8. Уведомление о перегреве.
9. Наложение поверх игр (оконный и безрамочный режимы).
10. Статистика батареи: оставшееся время, расход в ваттах, износ.
11. Список самых прожорливых процессов с кнопкой завершения.
12. Очистка временных файлов.
13. Журнал температур за сессию.
14. Игровой режим для выбранной игры.

Подробности — в [docs/SPEC.md](docs/SPEC.md), оформление — в [docs/DESIGN.md](docs/DESIGN.md).

## Чего в программе не будет

- Свои кривые вентиляторов, лимиты мощности, подсветка клавиатуры. Это делает штатный Control Center (служба GCUBridge); в программе будет кнопка для его запуска.
- Переключение «только встроенная графика».
- Остановка произвольных процессов и служб Windows.

## Технологии

Python 3.12+ и PySide6 (Qt). После отладки возможен перенос на C# или сборка в один exe.

## Запуск (появится вместе с кодом)

```
pip install -r requirements.txt
python -m x565_center
```

Температура процессора и обороты вентиляторов требуют запуска с правами администратора.
